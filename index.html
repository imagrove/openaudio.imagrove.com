Imagrove OpenAudio

基于 ESP32 与 Wi-Fi 的开源多房间音频系统
从全屋背景音乐到无线 5.1 环绕声，不被任何厂商锁定

订阅项目更新 文档 GitHub 仓库 查看进度

我们在构建什么

一套开放、可修复、可扩展的多房间音频系统。核心是树莓派/Armbian 盒子上的 Snapcast 服务端，加上多个 ESP32 音频节点。每个节点通过 Wi-Fi 接收音频流，同步播放，也可以独立分区。

它既能做全屋背景音乐，也能扩展成无线 5.1 环绕声。

不锁定硬件，不锁定软件，不锁定你的音箱。

为什么需要它

价格

一套品牌全屋方案动辄上万元；OpenAudio 单节点不到 ¥200，还能复用你已有的音箱。

不锁定

品牌方案把你锁进它的 App 与生态；这里固件、硬件、协议全部开放。

可修复

设备不该被一次软件更新变成废铁。开源意味着你可以自己修、自己改、自己升级。

它能做什么

全屋同步播放

所有房间播放同一首歌，人耳听不出任何延迟差。

分区独立播放

厨房听新闻，客厅听音乐，卧室听白噪音，互不干扰。

无线 5.1 环绕声（规划中）

3-4 个 ESP32 节点分别驱动左前、右前、中置、环绕和低音炮。

手机音源接入

iPhone 走 AirPlay，Android 走蓝牙或 DLNA，Spotify 走 Spotify Connect。

智能家居集成

原生对接 Home Assistant、Music Assistant、ESPHome。

低成本扩展

一个节点不到 ¥200，可以一个一个房间慢慢加。

开源可修复

固件、硬件设计、文档全部开放。你的设备不会被一次软件更新变成废铁。

常见问题

为什么会有爆音 / 卡顿？

关闭 Wi-Fi 省电模式、加大缓冲、让服务端走网线，通常就能解决。

延迟有多大？

背景音乐 1-2 秒可接受；需要音画同步的场景另议。

支持哪些音源？

AirPlay / 蓝牙 / DLNA / Spotify Connect / 本地文件。

一个节点能接几个音箱？

I2S 双声道输出，可接 2 个声道（如左 / 右）。

更多问题见 文档 FAQ。
